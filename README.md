# Morando

> Architecture framework for the JavaScript ecosystem.

## Introduction

**Morando** project is an architectural framework with tools that work much like a linter: 
it tells you when you’ve broken the fundamental rules of the Morando architecture.

However, it’s not deterministic. Given the same codebase, it’s not designed to produce a single “true” result, 
because there is no such thing as one true form for your project. 
You have to decide what works best for you and your organization.

That said, Morando is built on a well-defined set of ideas about **modules** and **layers**, 
which means it provides metrics you can use to evaluate whether a given change makes your project better or worse. 
In other words, it won’t tell you *where* your destination is,m but it *can* tell you whether you’re heading in the right direction.
